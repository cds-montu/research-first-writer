# Example: "Best open source web analytics tools" (listicle, 7 picks)

A full unattended run on a commercial-investigation keyword (en-US, 2026-11-01). The pages that rank are directories and a 2023 roundup, so the information gain comes from each vendor's own facts: licence, stack, cookies, hosted price and self-host limits.

| Step | File | What happened |
|---|---|---|
| 1 Brief | [01-brief.md](01-brief.md) | 7 picks for teams leaving Google Analytics |
| 2 Discover | [02-discover.md](02-discover.md) | 1 query; 3 ranking pages; 7 tools × repo + official site |
| 3 Score | [03-scores.md](03-scores.md) · [pages.json](pages.json) | top score 82.5; one page has no date, so freshness is left out rather than guessed |
| 4 Analyse | [04-analysis.md](04-analysis.md) | **2 directory claims are wrong** against the vendors' pages (Plausible script size, GoatCounter terms) |
| 5 Baselines | [05-baselines.md](05-baselines.md) | benchmark, depth, gap |
| 6 Research brief | [06-research-brief.md](06-research-brief.md) | 27 facts, plus a list of what could **not** be found and so isn't claimed |
| 7 Outline | [07-outline.md](07-outline.md) | identical fields for every pick, then a table |
| 8–9 Write and edit | [article.md](article.md) | 1,371 → 1,594 words; the edit added a missing must-cover, not padding |
| 10–11 Judge and report | [review-report.md](review-report.md) | **0.86, pass**; not ready: 1 proof slot and the image |

**What it teaches:** when the ranking pages are directories, beat them with primary-source facts in a consistent shape. When a fact cannot be found (PostHog's paid prices), say so and leave it out.
