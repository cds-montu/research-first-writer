# 4. Analyse

## alternativeto.net: "Google Analytics Alternatives: Top 12"
- **Angle:** a crowd-sourced directory, ranked by list order and user likes. **Strengths:** structured metadata, user comments, an explicit update date. **Weaknesses:** no method and no author; paid placements; coarse labels.
- **Claims checked against primary sources:**
  - Plausible: "Less than 1KB, no cookies, GDPR compliant." → **wrong**. Plausible's own page says "The Plausible tracking script is 2.5KB".
  - GoatCounter: "available as a hosted service (free for non-commercial use)" → **out of date**. The official site says "free for reasonable public usage".

## selfhostyourself.com: "20 self-hosted Google Analytics alternatives"
- **Angle:** a catalogue with stars, licence and last commit. **Strengths:** a self-hosting trade-offs section: "In exchange you take on hosting, backups and updates yourself." **Weaknesses:** no date or method; scope drift (a survey builder and a log analyser); no prices.

## zeabur.com: "Top 5 Self-Hosted, Open Source Alternatives to Google Analytics"
- **Angle:** a 2023 roundup with one use case per tool. **Strengths:** a clear, repeated per-tool structure; each tool tied to an audience. **Weaknesses:** no licence, stack or price data; dated; Countly is a mobile analytics tool, which is off-brief.

## The gap
None of the three pages gives licence implications, hosted prices, cookie behaviour from the vendor, or the limits of self-hosted editions (Plausible's missing features, PostHog's event ceiling).
